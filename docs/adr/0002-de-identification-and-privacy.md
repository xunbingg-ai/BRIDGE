# Real-patient cases must be de-identified; school-only storage

Cases may be based on real patients, so every real-patient case must be de-identified before entering the case library (fictional names, age ranges, date shifts, no identifiable fields such as ID numbers, employers, or addresses), case content must never be written to application logs, and all data is stored for in-campus teaching use only. Student passwords are hashed; no third-party analytics are used. This constraint is invisible in code, so it is recorded here rather than left for future readers to rediscover.
