# Phase-2 extensions recorded, not implemented

Voice input, exam mode with countdown, and batch case import are planned extensions. Decision: do not build them in phase 1, and do not let the skeleton couple to them — the chat UI stays text-based and no half-built audio, timer, or import code enters the repository. They are tracked as features feat-012, feat-013, and feat-014 in `feature_list.json` (status: not-started) so the roadmap is visible without polluting the codebase.
